## English

Engineering calculator for logic gate parameters (currently, **NOT gate** calculation under load is implemented). The program is designed for precise calculation of currents and voltages in transistor switches.

> ⚠️ **Note:** The project description (this README file) was temporarily drafted using **AI**, just to quickly set up the repository. The program code itself is completely handwritten by the author.

### 🛠 Current Features
- Calculation of collector current ($I_{csat}$) and base current ($I_{bsat}$).
- Determination of gate parameters under load ($V_{oh}$, $V_{ol}$, $V_{ih}$, $V_{il}$).
- Calculation of the fan-out coefficient (**Fan-Out**).
- Clean console output with automatic current formatting (`mA`, `uA`, `nA`, `pA`).

## Русский

Инженерный калькулятор параметров логических вентилей (на данный момент реализован расчет **NOT gate** под нагрузкой). Программа создана для точного расчета токов и напряжений в транзисторных ключах.

> ⚠️ **Примечание:** Описание проекта (этот README-файл) временно набросано с помощью **ИИ (AI)**, чтобы быстро оформить репозиторий. Сам код программы полностью написан автором вручную.

### 🛠 Текущие возможности
- Расчет тока коллектора ($I_{csat}$) и базы ($I_{bsat}$).
- Определение параметров гейта под нагрузкой ($V_{oh}$, $V_{ol}$, $V_{ih}$, $V_{il}$).
- Расчет коэффициента разветвления по выходу (**Fan-Out**).
- Красивый консольный вывод токов с автоматическим форматированием (`mA`, `uA`, `nA`, `pA`).
